# 📒 Customer Management API

API desenvolvida em Python para gerenciamento de clientes utilizando operações CRUD.

Este projeto foi criado para praticar arquitetura backend, organização de código e desenvolvimento de APIs REST.

---

# 🎯 Objetivo

Construir uma API capaz de realizar operações completas de cadastro, consulta, atualização e remoção de clientes.

---

# ✨ Funcionalidades

- Cadastro de clientes
- Consulta
- Atualização
- Exclusão
- Persistência em banco de dados

---

# 🛠 Tecnologias

- Python
- Flask
- SQLAlchemy
- SQLite

---

# 🏛 Arquitetura

Cliente

↓

API REST

↓

Flask

↓

SQLAlchemy

↓

SQLite

---

# 🚀 Como executar

```bash
git clone https://github.com/Monteirohh/customer-management-api.git

pip install -r requirements.txt

python app.py
```
